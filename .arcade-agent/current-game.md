# Active game

slug: fuseworks
started: 2026-10-23

Fuseworks is a top-down grid bomber in the classic arena-bomber tradition, with original IP: you are a
fuse-tech clearing a clockwork foundry of rival bots. Twist: **prism tiles** bend blast lines 90 degrees,
so every bomb is a routing puzzle and chain reactions can wrap around corners. Score rewards kills,
multi-kills per blast, chain reactions and speed across escalating foundry floors.
